# Intersect VRI with the LANDIS grid

Crops VRI1 to the grid extent, intersects with grid cells, and attaches
per-fragment area in m². Species/age fields are auto-detected for up to
n_species species columns, handling both GDB (SPECIES_CD_N) and
shapefile (SPECIES\_\_N) name variants.

## Usage

``` r
CreateInitialCommunitiesData(LandisGrid, VRI1FilePath, n_species = 2L)
```

## Arguments

- LandisGrid:

  SpatVector from CreateLandisGrid().

- VRI1FilePath:

  File path or c(dsn, layer) for the VRI 1 layer.

- n_species:

  Number of species/age field pairs to detect (default 2).

## Value

SpatVector of grid × VRI intersection features with MapCode, species,
age, and Area fields.
