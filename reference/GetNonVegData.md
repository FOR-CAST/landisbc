# Find the dominant BCLCS Level-4 non-vegetation code for each grid cell

Intersects VRI1 with the grid, excludes treed categories (TB, TC, TM),
and returns the Level-4 code with the largest area in each cell. Cells
where non-veg covers \< 50 % of the area AND whose MapCode is in
dicCleanMapCodes are excluded.

## Usage

``` r
GetNonVegData(LandisGrid, VRI1FilePath, grid_size, dicCleanMapCodes)
```

## Arguments

- LandisGrid:

  SpatVector from CreateLandisGrid().

- VRI1FilePath:

  File path or c(dsn, layer) for the VRI 1 layer.

- grid_size:

  Cell side length in metres.

- dicCleanMapCodes:

  Named list from CleanMapCodes() — used to detect vegetated cells.

## Value

Named list mapping MapCode (character) to dominant BCLCS Level-4 code
(character).
