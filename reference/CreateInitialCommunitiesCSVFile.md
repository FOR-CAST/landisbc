# Write the LANDIS-II v8 initial communities CSV file

Non-vegetated map codes (\< 10000) are omitted; LANDIS-II v8 treats
absent map codes as empty communities. CohortBiomass is always 0
(initial biomass is derived from cohort age during succession
initialisation).

## Usage

``` r
CreateInitialCommunitiesCSVFile(
  InitialCommunitiesDataList,
  dicCleanMapCodes,
  InitialCommunitiesCSV
)
```

## Arguments

- InitialCommunitiesDataList:

  data.frame with columns MapCode, SpeciesCode, Age.

- dicCleanMapCodes:

  Named list from CleanMapCodes().

- InitialCommunitiesCSV:

  Output file path for the CSV.

## Value

Invisibly NULL (writes to file as a side effect).
