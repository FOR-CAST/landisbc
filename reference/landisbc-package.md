# landisbc: British Columbia Study-Area Tools for LANDIS-II Workflows

Province of British Columbia data-preparation helpers for 'LANDIS-II'
forest-landscape simulation workflows – e.g. deriving observed
fire-severity distributions from provincial burn-severity data for
Dynamic Fire calibration, and translating Vegetation Resource Inventory
('VRI') polygons into 'LANDIS-II' initial-communities maps + CSVs.
Companion to 'landisutils' (the study-area-agnostic 'LANDIS-II'
tooling); BC-specific data sources and mappings live here so they can be
reused across British Columbia projects.
